## 7.0.1 (2025-10-27)

## [0.0.1] - Initial Release

### Added
- Initial implementation of Capacitor Pedometer plugin
- Support for step counting on iOS and Android
- Support for distance, pace, cadence, and floor counting on iOS
- Real-time pedometer updates
- Historical data queries (iOS)
- Permission handling for activity recognition
- Example app demonstrating plugin usage
